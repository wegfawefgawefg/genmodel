# Sound credits

The sound banks (`gen/models/*.sound.sexp`) use these recordings, found through the
Openverse API (https://api.openverse.org) and hosted on freesound.org. They are not in the
repo. To hear sounds, download them into `ref/sounds/` under the file names below
(`tools/sounds.py` cuts and filters them into the clips the viewer plays).
